# Trading Assistant — Frontend

React + Vite + TypeScript frontend for the Trading Assistant bot dashboard.

## Stack
- React 18, TypeScript, Vite
- Zustand (state), React Query (data fetching)
- Tailwind CSS + shadcn/ui
- Recharts (charts)

## Setup
```bash
cp .env.example .env
# Fill VITE_API_URL with the backend URL (Railway)
npm install --legacy-peer-deps
npm run dev
```

## Environment Variables
See `.env.example` for all available variables.
